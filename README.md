# E Technology & Solutions website

A responsive React + Vite company website using the supplied logo and a premium matte-black / neon-green visual theme.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the `e-technology-solutions` folder in VS Code.
4. Open the terminal and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address printed by Vite (usually http://localhost:5173).

## Before publishing

- Replace the sample email `hello@etechnologysolutions.com` in `src/App.jsx` with your real business email.
- Replace the sample project cards with real projects and screenshots.
- Connect the contact form to a backend or form service. The current form is a front-end demo and does not send/store messages.
- Add your official phone number and social links if you want them displayed.
- Review the company name spelling and logo image.

## Build for deployment

Run `npm run build`. Upload the generated `dist` folder to a static hosting provider such as Netlify or Vercel.
